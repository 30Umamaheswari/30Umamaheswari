### Featured projects

#### [IMDB Movie Analytics Dashboard](https://github.com/30Umamaheswari/IMDB)
Interactive 3-page Power BI report on 3,789 movies, showing budget, gross, profit and IMDB ratings by lead actor, director and country. Built on a star-schema model with DAX measures.
**Finding:** movies rated 8+ earned a median profit of about $30M, while those below 6 usually lost money.

<a href="https://github.com/30Umamaheswari/IMDB"><img src="https://raw.githubusercontent.com/30Umamaheswari/IMDB/main/images/director_journey.png" width="700" alt="IMDB Power BI dashboard"></a>

#### [House Rent Prediction App](https://github.com/30Umamaheswari/HouseRent)
Machine learning model that predicts monthly rent from property size, type, furnishing and amenities, served through a Streamlit app. Gradient Boosting cut average error to about ₹3,400, roughly half that of a simple baseline.
`Python` `scikit-learn` `Streamlit`

#### [Lead Conversion Prediction](https://github.com/30Umamaheswari/Lead-Prediction)
Analysis of 9,000+ EdTech leads to find which are likely to convert, with data cleaning, visual analysis and a Random Forest model (ROC AUC 0.86).
`Python` `Pandas` `Random Forest`
